Cara Agar Perangkat Desa Upload Tanpa Akses Drive

Agar pihak desa dapat **mengunggah file dari formulir aplikasi langsung tersimpan di Google Drive Anda** tanpa perlu login atau membuka folder Drive Anda, ikuti langkah 2 menit berikut:

  1. Buka Google Apps Script dengan Akun Google Drive Anda.
  2. Klik New Project (Proyek Baru) dan hapus semua kode bawaan.
  3. Salin (Copy) dan Tempel (Paste) kode Apps Script di bawah ini:
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var folderId = "1KRXt-rgZez7fH1NojylIyBqQ9E9o5r8g"; // ID Folder Drive Anda
    var folder = DriveApp.getFolderById(folderId);
    
    var contentType = data.mimeType || "application/octet-stream";
    var bytes = Utilities.base64Decode(data.base64);
    var blob = Utilities.newBlob(bytes, contentType, data.filename);
    var file = folder.createFile(blob);
    
    file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
    
    return ContentService.createTextOutput(JSON.stringify({
      result: "success",
      url: file.getUrl(),
      id: file.getId()
    })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({
      result: "error",
      error: err.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Klik tombol Deploy (Terapkan) → New Deployment (Terapkan Baru).
  2. Pilih Jenis: Web App.
  3. Set Execute as: Me (Email Anda).
  4. Set Who has access: Anyone (Siapa Saja).
  5. Klik Deploy, beri izin akses, lalu **Salin URL Web App** yang dihasilkan.
  6. Tempel URL Web App tersebut ke tombol Config & Status di aplikasi ini. Selesai!
