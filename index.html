Auto-Save ke Folder Drive "PengajuanPBBKolektifDesa"

Agar pihak desa dapat mengunggah Surat Pengantar yang langsung tersimpan di folder "PengajuanPBBKolektifDesa" tanpa login atau memiliki akses Drive Anda, lakukan langkah 2 menit berikut:

  1. Buka Google Apps Script dengan Akun Google Drive Anda.
  2. Klik New Project (Proyek Baru) dan hapus semua kode bawaan.
  3. Salin (Copy) dan Tempel (Paste) kode Apps Script terbaru di bawah ini:
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    
    // Target Folder: PengajuanPBBKolektifDesa
    var folderId = "1KRXt-rgZez7fH1NojylIyBqQ9E9o5r8g"; 
    var folder;
    
    try {
      folder = DriveApp.getFolderById(folderId);
    } catch(errF) {
      var folders = DriveApp.getFoldersByName("PengajuanPBBKolektifDesa");
      if (folders.hasNext()) {
        folder = folders.next();
      } else {
        folder = DriveApp.createFolder("PengajuanPBBKolektifDesa");
      }
    }
    
    var contentType = data.mimeType || "application/octet-stream";
    var bytes = Utilities.base64Decode(data.base64);
    var blob = Utilities.newBlob(bytes, contentType, data.filename);
    var file = folder.createFile(blob);
    
    // Set file agar bisa dilihat siapa saja melalui link
    file.setSharing(DriveApp.Access.ANYONE_WITH_LINK, DriveApp.Permission.VIEW);
    
    return ContentService.createTextOutput(JSON.stringify({
      result: "success",
      url: file.getUrl(),
      id: file.getId(),
      folderName: folder.getName()
    })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({
      result: "error",
      error: err.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}
  1. Klik tombol Deploy (Terapkan) → New Deployment (Terapkan Baru).
  2. Pilih Jenis: Web App.
  3. Set Execute as: Me (Email Anda).
  4. Set Who has access: Anyone (Siapa Saja).
  5. Klik Deploy, beri izin akses, lalu **Salin URL Web App** yang dihasilkan.
  6. Tempel URL Web App tersebut ke tombol Config & Status di aplikasi ini. Selesai!
